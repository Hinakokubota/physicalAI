## 構成と時間

- `index.html`: 2つのiframeを使った4章の連続再生。
- `physical-ai1.html`: OPと第1章、基準時刻0〜45秒。
- `physical-ai2.html`: 第2章、45〜85秒。
- `physical-ai3.html`: 第3章、85〜140秒。
- `physical-ai4.html`: 第4章と案内、140〜185秒。
- `physical-ai-flyer.html`: 静的なフライヤー。今回の動画ナレーションの対象外。

映像はHTML動画ファイルではなく、Canvas 2DにJavaScriptで毎フレーム描画するアニメーションです。1280×720の論理座標、ウィンドウへのフィット、端末のピクセル密度を考慮した拡大に対応しています。CSSは主に配置・背景・iframe表示を担い、図形、文字、フェード、ロボットの動きはJavaScriptが描画します。外部ライブラリ、音声要素、API通信はありません。

`scene(T, a, b, fn)` が開始を含み終了を含まない区間 `[a,b)` を判定し、`fn(T-a, T)` を呼びます。各シーンは0.45基準秒でフェードインし、末尾0.30基準秒でフェードアウトします。字幕は `SUBS`、見出しは `telop`、章表示は `CH_LABEL`、全体進行は `CHAPTERS` によります。字幕は各シーン内でさらに切り替わります。JSONにはその元の時刻と文字列も保存しています。

基準タイムラインは185秒（3分05秒）。全ページの初期値は `SLOW=2` なので、実際の再生は370秒（6分10秒）です。以下の「基準時刻」はコードの時刻、「現在の実再生時刻」は初期値で通し再生したときの経過時間です。途中でテンポ・章を変更した場合には単純な2倍の対応になりません。

## 再生と操作

子ページの `now()` は `performance.now()` を基に `T0 + elapsed / SLOW` を返します。一時停止時は `held` の時刻を保持し、再開時は `base` を調整して時間の連続性を保ちます。`requestAnimationFrame` が描画、`setInterval(now, 200)` が埋め込み再生時の終了検出を補います。単体表示は自章をループし、`#once` では章の終端で止まり `ended` を通知します。

| 操作 | index.html（通し再生） | 各章を単体表示 |
|---|---|---|
| Space | 表示中の章を停止・再開 | 停止・再開 |
| ← / → | 現在の章の基準時刻を±1秒 | 基準時刻を±1秒 |
| ↑ / ↓ | SLOWを±0.05、範囲0.5〜3 | 同左 |
| 1〜4 | 選んだファイルの先頭から再生 | `CH_LABEL`の配列添字に対応。通し再生の章選択とは異なる |
| Home | ハンドラなし | そのファイルの先頭へシーク。停止状態は維持 |
| URL `#t=秒` / `seekTo(秒)` | 親では未対応 | 動画全体の基準時刻で静止表示 |

indexは次章を `#once&hold&slow=...` で裏のiframeに読み込み、子の `ready` / `ended` を `postMessage` で受信します。終了時にiframeを交換し、次章へ `restart` を送ります。第4章の後は第1章へ戻ります。メッセージが来ない場合のみ `DUR[chap] * SLOW` のタイマーを保険に使います。この保険タイマーは一時停止やテンポ変更と完全には同期していないため、音声同期時には共通タイムラインに統一する必要があります。

現状、全体で同じ「時刻の意味」は使っていますが、各iframeの時計は別です。親には全体の再生時刻を管理する共通の時計がありません。音声ON/OFF、最初からの全体リスタート、MP3再生も未実装です。

## ③以降の実装方針（確認待ち）

- `narration/narration.ja.json`を編集元とし、別の生成スクリプトが `OPENAI_API_KEY` を環境変数から取得する。未設定なら生成せず、設定方法をREADMEで案内する。キーをHTML・JavaScriptや保存原稿に埋め込まない。
- 音声モデルは `gpt-4o-mini-tts`。落ち着いた日本語でMP3を生成し、`audio/scene-01.mp3`〜`audio/scene-20.mp3` に保存する。音声・モデル・指示などの変更をハッシュで検出し、変更したシーンだけ再生成する。音声の声種は未確定。
- HTML再生はローカルMP3だけを使用する。OpenAI API通信は音声生成スクリプトの実行時に限定する。
- 通し再生では親が再生時刻と状態を一元管理し、子Canvasと音声を同じ時刻に合わせる案。単体の章でも同じ時刻モデルを使用する。
- 停止・再開・最初から・シーク・章選択・ループ時には音声位置と状態を同時に更新し、非表示iframeの音声や前のシーンの音声を停止する。音声ON/OFFを追加する。
- 音声付き自動再生はブラウザで制限されるため、最初のクリック等で音声を有効にする必要がある。現在の見た目を保ち、操作部は最小限とする。
- MP3生成後に長さを実測し、字幕・動作・発話のタイミングを調整する。ローカルサーバーとブラウザで、音声・映像の同期、停止再開、シーク時の重複防止を検証する。再生・再生成方法をREADMEに記載する。

この段階ではAPIキーの確認やAPI呼び出しを行っていません。③以降は原稿確認後に着手します。
